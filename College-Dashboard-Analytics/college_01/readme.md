
# College_01 – Student Performance Analytics Dashboards

This folder contains Power BI dashboards developed to analyze **student academic and contest performance** for an anonymized institution referred to as **College_01**.

## 📊 Dashboards Included

### 1. BCA/MCA Performance Analysis
- Evaluates student performance across BCA and MCA programs  
- Key metrics include:
  - Total points
  - MCQs answered correctly
  - Programming problems solved
  - Performance categories (Poor, Below Average, Average, Good)
- Provides branch-wise, year-wise, and student-level insights

### 2. Contest Performance Analysis
- Analyzes student performance across multiple contest levels
- Highlights participation trends and scoring patterns across branches
- Helps identify overall strengths and areas for improvement in contests

---

## 🔐 Data Privacy & Confidentiality
- All student-related data has been **fully anonymized**
- Real student names and identifiers have been replaced with **system-generated IDs**
- The actual institution name has been abstracted as **College_01**
- No raw data files are included in this repository

---

## 🛠 Tools Used
- Power BI  
- Power Query (for data transformation and anonymization)  
- DAX for calculated measures and KPIs

These dashboards are shared **strictly for analytical and portfolio demonstration purposes** and follow standard data privacy and confidentiality best practices.
