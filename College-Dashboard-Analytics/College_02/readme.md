# College_02 – Branchwise & Overview Performance Dashboards

This folder contains Power BI dashboards created to analyze **branch-level and overall student performance** for an anonymized institution referred to as **College_02**.

## Dashboards Included

### 1. Branchwise Dashboard
- Provides detailed performance insights across academic branches  
- Key metrics include:
  - Total students and pass percentage
  - Average total score, MCQ score, and programming score
  - Pass vs Fail distribution
  - Performance categories such as Top Scorer, Good, Average, Below Average, and Very Poor
- Includes student-level drill-downs using anonymized student IDs

### 2. Overview Dashboard
- Presents a high-level summary of overall academic performance  
- Covers:
  - Branch-wise student distribution
  - Branch-wise average scores
  - Overall pass vs fail analysis
  - Key performance indicators for quick comparison across branches

---

## Data Privacy & Confidentiality
- All student data has been **fully anonymized**
- Real student names and identifiers have been replaced with **system-generated IDs**
- The actual institution name has been abstracted as **College_02**
- No raw data files or personally identifiable information (PII) are included in this repository

---

## Tools Used
- Power BI  
- Power Query (for data transformation and anonymization)  
- DAX for calculated measures and KPIs
