# DDA-_Contest--STUDENT-EVALUATION

ABC College Student Evaluation System

A data analytics project designed to evaluate and visualize student performance in competitive programming contests. The system processes contest leaderboard data, performs analytical transformations, and generates interactive Power BI dashboards to support performance assessment and academic insights.

📊 Project Overview

The ABC Student Evaluation System focuses on analyzing programming contest performance data to provide:

Contest-wise and overall performance analytics

Trend analysis across multiple contests and branches

Interactive dashboards for academic and training insights

Identification of high-performing and low-performing segments

This project demonstrates practical skills in data cleaning, exploratory data analysis, KPI tracking, and dashboard development.

🗂️ Data Architecture (High-Level)
Data Sources

Contest leaderboard exports (CSV format)

Student metadata (branch, academic year, registration details)

⚠️ Note: All datasets used in this project are anonymized and do not contain sensitive or personally identifiable information.

Data Flow

Raw contest data ingestion

Data cleaning and normalization

Dataset consolidation for analysis

Dashboard-ready structured output

🎨 Power BI Dashboard
Key Dashboard Features

Contest-wise leaderboards and rankings

Score and performance trend analysis

Branch-wise and contest-wise comparison

Interactive filters for contests and categories

Drill-down analysis for deeper insights

Design Highlights

Consistent color theme for readability

KPI-focused visuals for quick interpretation

Clean layout optimized for analytical reporting

🔄 Data Processing Workflow
Analytical Steps
